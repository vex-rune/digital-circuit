# 手搓计算机

## 冯诺依曼的四个基本组件
1. **存储器**
2. **逻辑单元 ALU**
3. **控制单元**
4. **输出输出**

## 存储概念
- 要求程序也必须在内存中

## 指令的顺序执行
- 由一段有限的指令组成
- 控制单元提取指令,解释指令,执行指令

# 计算机组成部件
- CUP 控制单元
- 内存 存储程序和数据
- 输出输出
