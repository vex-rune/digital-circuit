# 数字电路与计算机组成

从零开始构建计算机，探索数字系统的底层原理。

## 项目概述

使用 [Digital](https://github.com/hneemann/Digital) 电路模拟器，逐步从基础逻辑门构建到完整计算机。

## 演进路径

```
基础逻辑门 → 组合电路 → 时序电路 → 简易计算机
```

## 核心概念

### 基础电路
- **逻辑门**：AND、OR、NOT、NAND、XOR 等
- **组合逻辑**：输出仅取决于当前输入

### 时序电路
- **锁存器**：电平敏感的存储单元
- **触发器**：边沿触发的存储单元
- **寄存器**：多个触发器组合

### 计算机组成
- **CPU**：控制单元 + ALU
- **内存**：存储程序和数据
- **总线**：数据传输通道
- **I/O**：输入输出设备
