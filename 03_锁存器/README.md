# NAND型SR锁存器

## 真值表

| S | R | Q | Q' | 说明 |
|---|---|---|---|------|
| 0 | 0 | 1 | 1 | **无意义状态 (非法)** |
| 0 | 1 | 1 | 0 | 置位 (Set) |
| 1 | 0 | 0 | 1 | 复位 (Reset) |
| 1 | 1 | 保持 | 保持 | 记忆状态 |

## 无意义状态说明

当 **S=0 且 R=0** 时，两个NAND门的输出都为1，违背了Q和Q'必须互补的基本原则。这种状态在实际应用中应当避免。

### 原因分析
- Q和Q'应该是互补的（一个为1时，另一个为0）
- S=0, R=0 时会导致Q=1且Q'=1，这违反了锁存器的基本约束
- 从这种状态转换到其他状态时，结果不确定（取决于实际电路延迟）

### 解决方案
使用**门控SR锁存器**或**JK锁存器**，通过添加控制信号来避免这种状态。

# 门控SR锁存器

## 电路结构

门控SR锁存器在基础SR锁存器基础上增加了**使能信号(en)**，只有当en=1时，输入信号才有效。

```
S ──┬──NAND─┬─→ S' ──→ SR锁存器
en ─┘      │
           └─NAND─┬─→ R' ──→ SR锁存器
R ──────────────┘
```

## 真值表

| en | S | R | Q | Q' | 说明 |
|----|---|---|---|---|------|
| 0 | x | x | 保持 | 保持 | **使能关闭，保持状态** |
| 1 | 0 | 0 | 1 | 1 | **无意义状态 (非法)** |
| 1 | 0 | 1 | 1 | 0 | 置位 (Set) |
| 1 | 1 | 0 | 0 | 1 | 复位 (Reset) |
| 1 | 1 | 1 | 保持 | 保持 | 记忆状态 |

## 工作原理

- **en=0**：两个NAND门输出都为1，锁存器进入保持状态，忽略S和R的输入
- **en=1**：功能与基础SR锁存器相同，S和R信号正常起作用

## 进化意义

门控SR锁存器解决了基础锁存器的**同步控制问题**，可以控制何时允许数据写入，这是数字系统中寄存器工作的基础。

# D寄存器（EN开关）

## 电路结构

D寄存器在门控SR锁存器基础上增加了**非门**，将D信号取反后连接到R端。

```
D ──┬──NAND1─┬─→ S' ──→ SR锁存器
en ─┘        │
              └─NAND2─┬─→ R' ──→ SR锁存器
NOT ← D ─────────────┘
```

## 核心改进

通过非门确保 **S' = NOT(D)** 和 **R' = D**，**永远消除了无意义状态**。

## 真值表

| en | D | S' | R' | Q | Q' | 说明 |
|----|---|----|----|---|---|------|
| 0 | x | 1 | 1 | 保持 | 保持 | 使能关闭，保持状态 |
| 1 | 0 | 1 | 0 | 1 | 0 | **置位（存入1）** |
| 1 | 1 | 0 | 1 | 0 | 1 | **复位（存入0）** |

## 工作原理

- **en=0**：两个NAND输出都是1，锁存器保持
- **en=1, D=0**：S'=1, R'=0 → Q=1（存入1）
- **en=1, D=1**：S'=0, R'=1 → Q=0（存入0）

## 进化对比

| 特性 | 门控SR锁存器 | D寄存器 |
|------|-------------|---------|
| 输入 | S、R两个信号 | **D一个信号** |
| 无意义状态 | **存在** (S=0,R=0) | **消除** |

D寄存器通过非门保证S和R永远互补，从根本上解决了无意义状态问题，是**最常用的数据寄存器**。

# D触发器（边沿触发）

## 电路结构

D触发器采用**主从结构**，两个D寄存器串联，时钟信号相同。

```
D ──→ [D寄存器(主)] ──→ Q1 ──→ [D寄存器(从)] ──→ Q
                                      ↑
                                   同一en信号
```

## 主从工作原理

| 时钟(en) | 主寄存器 | 从寄存器 | 说明 |
|----------|---------|---------|------|
| 0→1 (上升沿) | **采样D** | 保持 | 准备数据 |
| 1 | 保持 | 保持 | 稳定传递 |
| 1→0 (下降沿) | 保持 | **采样Q1** | **输出更新** |

## 边沿触发效果

```
en:  ┌──┐    ┌──┐    ┌──┐
   ──┘  └──┘  └──┘  └──┘
       ↑    ↓    ↑    ↓
     上升沿  下降沿  上升沿  下降沿

D:   A    B    C    D    ← 每个上升沿的数据

Q:   A  →  B  →  C  →  D  ← 每个下降沿才更新！
```

## 进化对比

| 特性 | D锁存器 | D触发器 |
|------|---------|---------|
| 触发方式 | 电平触发 | **边沿触发** |
| en=1期间 | Q随D变化 | Q保持稳定 |
| 更新时机 | en变化时 | **仅在边沿瞬间** |

D触发器解决了数据稳定性问题，是时序电路的核心组件。

# 寄存器（4位并行存储）

## 电路结构

寄存器由**4个D触发器**并行组成，共享同一个时钟信号。

```
4位输入 D[3:0] ──→ [D_FF][D_FF][D_FF][D_FF] ──→ 4位输出 Q[3:0]
                     ↑         ↑         ↑         ↑
                   时钟C ──────┴─────────┴─────────┘
```

## 4个D触发器并行工作

| D_FF | 输入 | 时钟 | 输出 |
|------|------|------|------|
| FF0 | D0 | C↓ | Q0 |
| FF1 | D1 | C↓ | Q1 |
| FF2 | D2 | C↓ | Q2 |
| FF3 | D3 | C↓ | Q3 |

## 进化总结

| 文件 | 名称 | 核心功能 |
|------|------|----------|
| 01 | SR锁存器 | 基础存储，有无意义状态 |
| 02 | 门控SR锁存器 | 增加en控制 |
| 03 | D寄存器 | 单比特存储，消除无意义 |
| 04 | D触发器 | 边沿触发，解决稳定性 |
| **05** | **寄存器** | **4位并行存储，同步更新** |

## 实际应用

```
寄存器 = N个D触发器 + 共享时钟
        = 可存储N位二进制数据
        = CPU的ALU、内存单元的基础
```
